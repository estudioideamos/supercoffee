# Supercoffee

Experiencia web inmersiva para una cafetería de especialidad, construida con Next.js y animaciones GSAP.

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación queda disponible en `http://localhost:3000`.

## Verificación

```bash
npm run lint
npm run build
```

El proyecto genera una exportación estática compatible con GitHub Pages. Cada push a `main` publica automáticamente mediante `.github/workflows/pages.yml`.
